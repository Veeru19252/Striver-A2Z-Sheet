# 🔥 The 6 Greedy Patterns You MUST Recognize

### 1. Sort → Pick Best

```
Sort
 ↓
take locally optimal choice
 ↓
continue
```

Examples:

- Activity Selection
- Assign Cookies
- Boats to Save People
- Two City Scheduling

---

### 2. Interval Greedy

Usually:

```
sort by ending time
```

Then greedily select intervals.

Classic:

**LC 435 → Non-overlapping Intervals**

**LC 452 → Minimum Arrows**

---

### 3. Greedy + Heap

This combination is **massive in interviews**.

```
Greedy choice
      +
Priority Queue
```

Examples:

- IPO
- Furthest Building
- Task Scheduler
- Maximum Performance
- Minimum Cost to Hire K Workers

---

### 4. Greedy + Stack

Examples:

- Remove K Digits
- Remove Duplicate Letters
- Monotone Increasing Digits

The core idea:

```
If current choice makes the previous choice worse,
undo the previous choice.
```

---

### 5. Greedy Range Expansion

Examples:

- Jump Game
- Jump Game II
- Video Stitching
- Minimum Taps

Think:

```
current reachable range
        ↓
find farthest next reach
        ↓
expand
        ↓
repeat
```

---

### 6. Greedy Proof

This is the part people skip because apparently proving correctness is less exciting than collecting submissions. 😭

For every greedy solution, ask:

> **Why is my local choice safe?**

Usually the proof comes from:

- **Exchange argument**
- **Stays-ahead argument**
- **Cut property**
- **Dominance**
- **Optimal substructure**

If you can explain *why* the greedy choice cannot hurt the final answer, you've actually learned Greedy rather than memorized another template.

For your preparation, I'd specifically go:

That sequence will make the later problems much less disgusting. 🧠🔥
