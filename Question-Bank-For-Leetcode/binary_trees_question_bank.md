# 🚨 The Most Important Binary Tree Patterns

### 1. Height Pattern

```
int height(Node* root) {
    if(!root) return 0;

    return 1 + max(
        height(root->left),
        height(root->right)
    );
}
```

This tiny pattern is the parent of approximately **900 tree problems**. Humanity really did discover recursion and then decide to put everything inside it.

---

### 2. Diameter Pattern

Think:

```
        node
       /    \
      L      R

answer through node =
height(L) + height(R)
```

This leads directly to:

**LC 543**

and eventually to much nastier tree-DP problems.

---

### 3. DFS Path Pattern

For:

- Path Sum
- Root-to-leaf paths
- Maximum path
- Good nodes
- Ancestor problems

think:

```
root
 ↓
DFS
 ↓
carry information
 ↓
return information
```

---

### 4. Level Order Pattern

Whenever the question says:

> level, depth, left/right view, width, nearest, shortest level

your first thought should be:

```
queue<TreeNode*> q;
```

---

### 5. LCA Pattern

```
             root
            /    \
           ...   ...
          /        \
         p          q
```

Questions involving:

- common ancestor
- distance between nodes
- path between nodes
- subtree relationships

often reduce to **LCA**.

---

### 6. Tree Construction

Memorize the relationship:

```
Preorder:
Root → Left → Right

Inorder:
Left → Root → Right

Postorder:
Left → Right → Root
```

Therefore:

```
Preorder + Inorder
        ↓
   Unique Tree

Postorder + Inorder
        ↓
   Unique Tree
```

This is one of those concepts that looks trivial until an interviewer puts a tree on the whiteboard and suddenly everyone remembers they have somewhere else to be. 😭
