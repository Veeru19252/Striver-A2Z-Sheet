# 🔥 The Bit Tricks You MUST Know

Before going into the medium/hard section, these should be automatic:

```
// Check ith bit
n & (1 << i)

// Set ith bit
n | (1 << i)

// Clear ith bit
n & ~(1 << i)

// Toggle ith bit
n ^ (1 << i)

// Remove rightmost set bit
n & (n - 1)

// Isolate rightmost set bit
n & (-n)

// Check power of 2
n > 0 && (n & (n - 1)) == 0

// XOR swap
a ^= b;
b ^= a;
a ^= b;
```

And the big one:

```
// Number of set bits
while(n) {
    n &= (n - 1);
    count++;
}
```

### 🚨 One thing to understand deeply

**XOR is the star of beginner/intermediate bit manipulation.**

Remember:

```
x ^ x = 0
x ^ 0 = x
x ^ y ^ x = y
```

That's why these work:

- Single Number
- Missing Number
- Two Unique Numbers
- XOR prefix problems
- XOR subarray problems
- XOR queries

Then comes the genuinely nasty stuff:

```
Bitmask
   ↓
Subset representation
   ↓
Binary Trie
   ↓
XOR optimization
   ↓
Bitmask DP
   ↓
State compression
```

For your **Striver A2Z preparation**, I'd finish the **20 must-do problems above first**, then move into the 50 medium questions. That gives you the actual bit-manipulation toolkit before the problems start throwing 20-bit masks at your face like it's perfectly reasonable. 😭🔥
