🚨 Heap Patterns You MUST Know

1\. Kth Largest

For Kth largest, think:

priority_queue\<int, vector\<int>, greater\<int>> pq;



for(int x : nums) {

&#x20;   pq.push(x);



&#x20;   if(pq.size() > k)

&#x20;       pq.pop();

}



return pq.top();



You're maintaining the K largest elements.

2\. Kth Smallest

Use a max heap of size K:

priority_queue\<int> pq;



for(int x : nums) {

&#x20;   pq.push(x);



&#x20;   if(pq.size() > k)

&#x20;       pq.pop();

}



return pq.top();



3\. Two Heaps

For running median:

&#x20;       MAX HEAP

&#x20;      /        \\

&#x20;smaller        larger

&#x20;      \        /

&#x20;       MIN HEAP



Maintain:

size(maxHeap) ≈ size(minHeap)



Then:

odd  → top of larger heap

even → average of both tops



4\. K-Way Merge

Whenever you see:

K sorted arrays/lists



your brain should immediately whisper:

"Heap."



Examples:

\- Merge K Sorted Lists

\- Smallest Range

\- Kth Smallest Matrix

\- K Pairs With Smallest Sums

5\. Heap + Greedy

This combination is extremely important for interviews.



Look for:

Repeatedly choose:

&#x20;   smallest

&#x20;      OR

&#x20;   largest

&#x20;      OR

&#x20;   currently best option



Examples:

\- Task Scheduler

\- Reorganize String

\- Furthest Building

\- IPO

\- Minimum Cost to Hire Workers

\- Maximum Performance

🔥 The biggest heap trick

Don't ask:

"Is this a heap problem?"



Ask:

"Do I repeatedly need the current minimum/maximum while the rest of the elements don't matter yet?"



If yes, there's a very good chance a priority queue is hiding in the bushes. 🌚
