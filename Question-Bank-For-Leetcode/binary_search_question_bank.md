# 🧠 Binary Search Pattern Order

This is the **actual order I'd recommend**, rather than doing 1 → 200 like a robot:

```
                    BINARY SEARCH
                         │
        ┌────────────────┴────────────────┐
        ↓                                 ↓
   Basic BS                         Search on Answer
        │                                 │
        ↓                                 ↓
 Lower Bound                         Minimize X
 Upper Bound                         Maximize X
 First / Last                        Feasibility
        │                                 │
        ↓                                 ↓
 Rotated Arrays                    Allocation
 Peak / Bitonic                    Capacity
        │                          Scheduling
        ↓
  2D Binary Search
        │
        ↓
 Partition / Median
        │
        ↓
 Advanced BS
```

### 🔥 The key skill

For every Binary Search problem, ask yourself:

> **"What exactly is monotonic here?"**

If you can't answer that, **don't write the `while` loop yet**.

That's the difference between actually understanding Binary Search and just having a suspiciously well-practiced template. 😭

**One important correction from the earlier lists:** some problems naturally overlap with other A2Z sections. That's unavoidable in a supplementary bank, but for your eventual master sheet we should assign each problem a **primary pattern** so the same problem isn't counted as both Binary Search and DP, or Sliding Window and Two Pointers, etc.
