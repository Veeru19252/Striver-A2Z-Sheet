# 🔥 The patterns you MUST master

Before moving into advanced recursion, you should be comfortable writing these **from memory**:

### 1. Pick / Not Pick

```
solve(i + 1);          // don't pick
solve(i + 1, curr);    // pick
```

### 2. For-loop recursion

```
for(int j = start; j < n; j++) {
    curr.push_back(a[j]);
    solve(j + 1);
    curr.pop_back();
}
```

### 3. Swap-based permutation

```
for(int j = i; j < n; j++) {
    swap(a[i], a[j]);

    solve(i + 1);

    swap(a[i], a[j]);   // backtrack
}
```

### 4. Constraint checking

For problems like **N-Queens/Sudoku**:

```
choose
   ↓
check valid?
   ↓
make choice
   ↓
recurse
   ↓
undo choice
```

### 5. Memoization

```
Recursion
   ↓
Repeated states?
   ↓
YES
   ↓
memo[state]
   ↓
DP
```

That's the progression that matters. **Don't memorize 200 recursion solutions. Lea**
