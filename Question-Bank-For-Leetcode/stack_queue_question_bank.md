# 🔥 The Stack Patterns You Need

Don't just solve these problems. Extract the pattern.

### 1. Basic Stack

```
stack<int> st;

st.push(x);
st.pop();
st.top();
st.empty();
```

### 2. Monotonic Increasing Stack

Usually for:

- Next smaller
- Previous smaller
- Histogram
- Minimum contribution

```
while (!st.empty() && a[st.top()] >= a[i])
    st.pop();
```

### 3. Monotonic Decreasing Stack

Usually for:

- Next greater
- Previous greater
- Stock span

```
while (!st.empty() && a[st.top()] <= a[i])
    st.pop();
```

### 4. Contribution Technique

This is **very important**:

```
            element
           /       \
 previous smaller   next smaller
       ↓                 ↓
      left              right
```

Used heavily in:

- Sum of Subarray Minimums
- Sum of Subarray Ranges
- Largest Rectangle
- Maximum Subarray Min-Product

# 🚀 The Queue Patterns

### Normal Queue

```
FIFO

front → [1 2 3 4] ← rear
          ↓
        remove
```

### Deque

```
push_front()
push_back()

pop_front()
pop_back()
```

### Monotonic Deque

The monster behind:

- Sliding Window Maximum
- Shortest Subarray ≥ K
- Constrained Subsequence Sum

Typical idea:

```
while (!dq.empty() && a[dq.back()] <= a[i])
    dq.pop_back();

dq.push_back(i);
```
